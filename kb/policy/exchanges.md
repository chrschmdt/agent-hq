# Exchanging items

Items from a delivered order can be exchanged for other options of the same product.

## Which orders can be exchanged

An order can be exchanged only when its status is **delivered**. Each item can be exchanged for an available item of
the same product with different options, such as another size or color. Exchanging for a different product is not
possible.

## Paying or receiving the difference

If the new items cost more or less, the difference is charged to or refunded to a payment method you choose. A gift
card must have enough balance to cover any amount due. There is no need to place a new order.

## What happens next

After you confirm every item to exchange, the status changes to **exchange requested**, and you receive an email
about returning the original items. A delivered order can be exchanged or returned once, so list every item in one
request.
