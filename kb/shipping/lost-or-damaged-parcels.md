# Lost or damaged parcels

If a parcel never arrives or arrives damaged, contact support.

## Damaged items

If an item arrives damaged, it can be returned or exchanged for the same product once the order shows as
**delivered**, like any other return or exchange.

## Parcels that never arrive

If a parcel is well past its promised date, support will look into it with the carrier and hand the case to a person
if it needs a decision outside the usual return and exchange options.
